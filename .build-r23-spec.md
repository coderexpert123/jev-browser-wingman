## Decisions (binding, with exact literals)

### D1. Fixture-server path rule — intake option (a), extended

`resolveStartUrl` is NOT touched (its three-branch pin,
`tests/bench-cap.test.ts:239`, stays green; local tasks resolve
`fixtureUrl + path`). The change is contained in `src/fixture-server.ts`'s
request handler. New resolution ORDER:

1. `pathname === '/'` → serve `fixtures/pages/index.html`.
2. Strip ONE trailing slash (`/x/` → `/x`) when `pathname.length > 1`.
3. Reject `pathname.includes('..')` (guard unchanged; it also kills
   backslash climbs, which need `..`).
4. Match single-segment `/^\/([^/]+)\.html$/` → `pages/<name>.html`
   (unchanged), OR nested `/^\/([^/.]+)\/([^/.]+)\.html$/` →
   `pages/<section>/<name>.html` (NEW; dots excluded per segment, so a
   nested segment can never hide `..`; three-plus segments fail the regex).
5. Otherwise 404. The `cookie` Set-Cookie special case stays keyed on the
   single-segment name `cookie` (which now also serves at `/cookie/`).
6. `?delay=` handling unchanged (matches `rawUrl`, applies after a
   successful match; nested paths included).

### D2. One fixture family, mirroring the-internet; the chain-* family is untouched

`fixtures/pages/chain-*.html` (9 files) are UNIT/E2E test fixtures pinned by
7 test files (`chain.test.ts`, `chain-e2e.test.ts`, `act-nav.test.ts`,
`adapter-cdp.test.ts`, `adapter-playwright.test.ts`, `conformance-ops.test.ts`,
`page-scripts.test.ts`): different element names, a sessionStorage state
machine, different link graphs. Repurposing them would rewrite 7 files'
pins and pollute unit fixtures with bench link graphs. Unification rule
applies to the MECHANISM (one fixture server, one pages directory — both
families live in `fixtures/pages/` and ride the same server), not to page
content. No existing file is modified; zero name collisions (verified
against the directory listing). Nested fixtures live in subdirectories
(`fixtures/pages/status_codes/404.html`), which `package.json` `files`
already ships (`"fixtures/pages"`).

### D3. The index fixture lists exactly the 12 served examples, not all 44

Deliberate deviation from live (44 links): a dead link turns a wandering
playwright-route cell into a 404 page and burns recovery rounds — the r22
acceptance (t9 forced <= 4 calls/cell) argues against it. Live hrefs are
kept verbatim INCLUDING the `/add_remove_elements/` trailing slash. Recorded
in the README honesty note (WP-E).

### D4. forgot_password: client-side submit, error banner, same URL

Form markup byte-faithful (action/method kept); a submit listener calls
`preventDefault()` and renders `<div data-alert id="flash" class="flash
error">Internal Server Error</div>` into `#flash-messages` (the layout's
real flash container, mirroring layout.erb's flash-error shape). This
reproduces the observed live branch (correction 2) deterministically: same
URL, observable banner, no server POST. The local t9 therefore exercises
the post-action/recovery machinery WITHOUT the 500 lottery — WP-E words
this honestly.

### D5. t13 infinite scroll: client-side deterministic appender

No XHR, no jscroll. A scroll listener appends `<div class="jscroll-added">`
blocks (tall, 400 px min-height, so each append creates real scroll room)
throttled to one per 250 ms, max 12. The oracle (>= 10 blocks) is reachable
by repeated scroll acts, matching the live loop shape. HONESTY NOTE
(WP-E + round notes): the growth-wait path still fires, but the network
latency component of live jscroll is gone — t13 cells measure the loop's
scroll/growth handling, not jscroll's fetch timing.

**dynamic_controls.html** — BODY (vanilla mirror of the deployed jQuery;
3000 ms toggle timer; both arms cycle both directions; `#loading` text
`Wait for it... ` inserted after the clicked button, removed at completion):
```html
<div class="example">
  <h4>Dynamic Controls</h4>
  <p>This example demonstrates when elements (e.g., checkbox, input field, etc.) are changed asynchronously.</p>
  <h4 class="subheader">Remove/add</h4>
  <br>
  <form id="checkbox-example">
    <div id="checkbox"><input type="checkbox"> A checkbox</div>
    <button autocomplete="off" type="button" onclick="swapCheckbox()">Remove</button>
  </form>
  <hr>
  <br>
  <h4 class="subheader">Enable/disable</h4>
  <br>
  <form id="input-example">
    <input type="text" disabled style="width: 30%;">
    <button autocomplete="off" type="button" onclick="swapInput()">Enable</button>
  </form>
</div>
<script>
function clearMessage() { var m = document.getElementById('message'); if (m) m.remove(); }
function showLoading(btn) {
  var d = document.createElement('div');
  d.id = 'loading';
  d.textContent = 'Wait for it... ';
  btn.after(d);
}
function finishLoading(btn, msg, beforeBtn) {
  var m = document.createElement('p');
  m.id = 'message';
  m.textContent = msg;
  if (beforeBtn) { btn.before(m); } else { btn.after(m); }
  btn.disabled = false;
  var l = document.getElementById('loading');
  if (l) l.remove();
}
function swapCheckbox() {
  var btn = document.querySelector('#checkbox-example button');
  btn.disabled = true;
  clearMessage();
  showLoading(btn);
  setTimeout(function () {
    var box = document.getElementById('checkbox');
    var msg;
    if (btn.textContent === 'Remove') {
      box.remove();
      btn.textContent = 'Add';
      msg = "It's gone!";
    } else {
      var d = document.createElement('div');
      d.id = 'checkbox';
      d.innerHTML = '<input type="checkbox"> A checkbox';
      btn.before(d);
      btn.textContent = 'Remove';
      msg = "It's back!";
    }
    finishLoading(btn, msg, true);
  }, 3000);
}
function swapInput() {
  var btn = document.querySelector('#input-example button');
  var input = document.querySelector('#input-example input');
  btn.disabled = true;
  clearMessage();
  showLoading(btn);
  setTimeout(function () {
    var msg;
    if (btn.textContent === 'Enable') {
      input.disabled = false;
      btn.textContent = 'Disable';
      msg = "It's enabled!";
    } else {
      input.disabled = true;
      btn.textContent = 'Enable';
      msg = "It's disabled!";
    }
    finishLoading(btn, msg, true);
  }, 3000);
}
</script>
```

window.addEventListener('scroll', function () {
